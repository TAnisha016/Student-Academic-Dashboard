# Student Academic Dashboard

## About the Project
The Student Academic Dashboard is a web-based project designed to display student academic information in one place. It includes sections for courses, assignments and student profile details.

## Technologies Used
- HTML
- CSS
- JavaScript
- Amazon Web Services (AWS)
- Amazon EC2
- Linux
- Apache Web Server

## Features
- Dashboard displaying academic information
- Courses section
- Assignments section
- Student profile section
- Hosted on AWS EC2

## Deployment
The project was deployed on an AWS EC2 instance using Amazon Linux and Apache Web Server. The website can be accessed through the public IP address of the EC2 instance.

## Project Structure
- `index.html` – Main dashboard page
- `css/` – Stylesheet files
- `js/` – JavaScript files
- `pages/` – Courses, assignments and profile pages
